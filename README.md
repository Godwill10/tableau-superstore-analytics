# Tableau Superstore Analytics

An interactive Tableau dashboard for exploring sales performance, profitability, product trends, and regional business results using the Superstore dataset.

![Superstore dashboard](screenshots/Screen%20Shot%202026-08-07%20at%2012.49.35%20AM.png)

## Project goals

- Turn transactional sales data into clear business insights
- Compare revenue and profit across regions, categories, and time
- Surface underperforming segments and opportunities for improvement
- Present key metrics in an executive-friendly dashboard

## Tools and skills

- Tableau
- Data visualization
- Dashboard design
- KPI analysis
- Business intelligence
- Interactive filtering

## View the workbook

Download [`superstore-dashboard.twbx`](dashoards/superstore-dashboard.twbx) and open it with Tableau Desktop or Tableau Public.
